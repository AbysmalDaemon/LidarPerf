# AI Usage and Human Responsibility

LidarPerf uses AI tools substantially during software development and research support.

AI assistance may include:

- literature discovery and synthesis;
- implementation drafts and refactoring;
- unit/integration test generation;
- documentation and issue/PR drafting;
- debugging assistance;
- experimental-analysis code;
- manuscript drafting and editing.

The project does **not** treat AI output as evidence of correctness.

Human responsibility remains with the project author/maintainer, including:

- approving benchmark semantics and protocol decisions;
- validating implementation behavior with tests and independent references;
- inspecting representative raw benchmark results;
- approving scientific hypotheses and experimental design;
- reviewing every scientific claim before publication;
- complying with the AI-disclosure policy of each publication venue.

For research outputs, material AI use will be disclosed according to the destination venue's policy. The project log records significant decisions, failures, fixes, and validation work so that authorship and validation are auditable rather than implied by code provenance alone.
